# Loja PHP

Mini loja virtual feita com PHP puro.

## Funcionalidades

- Catálogo de produtos
- Carrinho salvo na sessão
- Adicionar e remover itens
- Frete grátis acima de R$ 300
- Desconto automático de 10% acima de R$ 600
- Layout responsivo

## Como rodar

Com PHP instalado:

```bash
php -S localhost:8000
```

Depois acesse:

```txt
http://localhost:8000
```

- PHP
- HTML
- CSS
